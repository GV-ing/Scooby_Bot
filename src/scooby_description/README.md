# scooby Description Package

This package contains urdf descriprion for the Fratomo robot used for the Robotics Lab course

### Launch files

- **Simulazione Gazebo:**
  ```bash
  ros2 launch scooby_description scooby_gazebo.launch.py
  ```

- **Visualizzazione RViz:**
  ```bash
  ros2 launch scooby_description scooby_rviz.launch.py
  ```
